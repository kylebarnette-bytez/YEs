Instructions to compile and run:
- Navigate to the /src/ folder
- Inpute the following commands:
    - javac board/\*.java game/\*.java gui/\*.java pieces/\*.java position/\*.java utils/*.java
    - java gui/GuiMain

List of features:
- Interactive chess GUI that allows for moving peices by clicking on squares
- Highlighting which squares a piece can move to if selected
- A game history panel
- An undo button
- Game saving and loading
- Timers for both players
- New game and exit button
- Pop-up for when game ends
